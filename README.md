# Real Estate Business Analytics project

## Project Overview
An end-to-end business analytics solution that extracts live real estate data via an API,cleans and transforms 
the data using python/pandas,loads it into a postgreSQL,database,perform advanced SQL analysis,and visualizes
executive insights using an interactive power BI dashboard.

## project Structure 
- ' data/' : Contains raw and cleaned CSV datasets.
- ' Scripts/': python scripts for extraction ('extract.py'),cleaning ('clean.py'),and database loading .
- 'sql/': SQL scripts containing analytical queries .
- 'powerbi/': Interactive Power BI dashboard('.pbix').
- 'screenshots/': visual previews of the dashboard.

## Technologies Used
- **Python**(Requests,Pandas,Dotenv)
- **PostgreSQL & SQL**
- ** PowerBI & DAX **
- ** Git & GitHub**
